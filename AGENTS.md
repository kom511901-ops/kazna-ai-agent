# Инструкции для Codex по этому репозиторию

## Общие правила
- Язык кода и комментариев: комментарии — по-русски, идентификаторы — по-английски.
- Всегда async там, где есть I/O.
- Каждая задача = отдельный PR с тестами. Не мержить без зелёных тестов.
- Запуск: `ruff check`, `mypy app`, `pytest` — всё должно проходить.

## Доменные правила продукта (НАРУШАТЬ НЕЛЬЗЯ)
1. Никаких захардкоженных сумм, порогов, номеров статей/постановлений в коде.
   Вся нормативка — только из БЗ.
2. Ответ агента строится ТОЛЬКО на переданных источниках. Нет источника —
   честный отказ + рекомендация уточнить в ТОФК.
3. Каждое нормативное утверждение сопровождается ссылкой на источник и годом/редакцией.
4. Во все ответы по денежным/спорным вопросам подставляется дисклеймер
   «справочная информация, не юридическая консультация».
5. Модель за абстракцией провайдера. Смена модели = правка конфига, не кода.

## Тесты — это критерии приёмки
Для каждой задачи реализуй тесты из соответствующего раздела плана.
Eval-набор (/evals) прогоняется на T4 и далее — он не должен деградировать.
